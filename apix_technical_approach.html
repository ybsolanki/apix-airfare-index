Real-time Airfare Price Index (APIx)

Official Technical Approach & Methodology Specification

1. Executive Summary & Problem Context

Traditional Consumer Price Index (CPI) calculations rely on static monthly manual surveys. In modern aviation, dynamic pricing algorithms adjust airfares multiple times daily based on demand, booking windows, and fuel prices. APIx solves this gap by establishing an automated, high-frequency Airfare Price Index engine for MoSPI and RBI.

2. Technical Architecture Overview

  • Ingestion Layer: Scraper adapters extracting airfares from airline APIs and OTAs adhering to ethical rate limits.
  • Data Cleaner & Normalizer: IQR outlier filtering (< ₹1,000 or > ₹60,000) and economy baggage standardizing.
  • Index Calculation Engine: Real-time weighted Laspeyres index relative to base period $t_0 = 100.0$.
  • REST API & Dashboard: Python FastAPI backend serving an interactive React analytics dashboard.

3. Mathematical Index Calculation Formula

Route Index: I_{r,t} = ( P_{r,t} / P_{r,0} ) × 100
National Index: I_{total,t} = ∑ ( w_r × I_{r,t} ) [where ∑ w_r = 1.0]
